How it works

  1. You ask

    Type one sentence to your agent.

  2. Your agent reads the change

    It sorts the files into parts and explains what's new.

  3. You explore

    Open one part at a time. New words come with a meaning.

  4. You comment

    Your notes go back to your agent. Questions get answers.

Set up in a minute

You need Node 18 or newer and git. Nothing else.

# 1. Get diffotator
git clone https://github.com/adisagar2003/diffotator.git
cd diffotator

# 2. Make the diffotator command work anywhere
ln -sf "$PWD/bin/diffotator.js" ~/.local/bin/diffotator

# 3. Tell your agent how to use it (Claude Code shown)
cp claude/diffotator.md ~/.claude/commands/
# Another agent? Add claude/diffotator.md to its instructions.

Then ask your agent:

use diffotator to review <your pull request link>
